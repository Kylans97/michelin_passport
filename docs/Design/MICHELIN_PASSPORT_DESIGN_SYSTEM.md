# Purpose

The Michelin Passport Design System defines the visual and emotional identity of the product.

It exists to ensure that every screen, interaction and animation contributes to one coherent experience.

This document is not a collection of UI rules.

It is a philosophy for designing timeless digital experiences.

---

# Design Philosophy

Michelin Passport is not designed to impress.

It is designed to disappear.

The interface should quietly frame the memories it preserves.

When a user opens Michelin Passport, the focus should never be the application itself.

The focus should always be the experience.

---

# Our North Star

> Michelin Passport never competes with the memory.

> It frames it.

---

# Design Values

Everything we design should embody three values.

## Elegant

Elegant design removes rather than adds.

The interface should feel refined, balanced and effortless.

Nothing should appear decorative without purpose.

---

## Intentional

Every element exists for a reason.

Every colour.

Every animation.

Every piece of spacing.

If an element cannot justify its existence, it should not exist.

---

## Enduring

Michelin Passport should feel as modern in ten years as it does today.

We do not design for trends.

We design for longevity.

---

# Emotional Design

Michelin Passport should evoke emotion before functionality.

The product should feel:

- Calm
- Personal
- Sophisticated
- Inspiring
- Reflective
- Premium

The experience should resemble opening a beautifully crafted travel journal rather than browsing a database.

---

# Quiet Luxury

Luxury does not need to announce itself.

Our interface embraces restraint.

We favour:

- generous whitespace
- subtle typography
- premium photography
- restrained colours
- thoughtful motion

Luxury is experienced through quality, not decoration.

---

# Photography First

Photography is the heart of Michelin Passport.

Images should lead the experience.

Text supports the image.

The interface should never compete with photography.

A memorable dinner deserves visual space.

---

# Timeless Design

Avoid short-lived design trends.

Do not introduce visual effects simply because they are fashionable.

Design decisions should remain relevant for many years.

Timelessness always outweighs novelty.

---

# Visual Hierarchy

Users should instinctively know where to look.

Hierarchy should be achieved through:

- scale
- spacing
- typography
- photography

Not through excessive colours or decorative elements.

---

# Colour Philosophy

Colour communicates meaning.

It should never become visual noise.

Neutral colours form the foundation.

Accent colours should remain rare and meaningful.

The interface should feel warm rather than clinical.

---

# Typography

Typography creates rhythm.

Restaurant names deserve prominence.

Dates provide context.

Awards provide credibility.

Personal notes provide emotion.

Every level of text should have a clear purpose.

---

# White Space

White space is not empty space.

It gives memories room to breathe.

Generous spacing creates calm and improves readability.

Never fill empty space simply because it exists.

---

# Motion

Motion should feel natural.

Animations should:

- guide attention
- reinforce hierarchy
- communicate state

Animations should never exist purely for entertainment.

Fast enough to feel responsive.

Slow enough to feel elegant.

---

# Navigation

Navigation should disappear into habit.

Users should always know:

Where they are.

Where they came from.

Where they can go next.

Navigation should reduce thinking.

---

# Components

Every component should feel like part of the same family.

Examples include:

- Restaurant Cards
- Hotel Cards
- Visit Cards
- Award Badges
- Photo Galleries
- Maps
- Ratings

Consistency builds trust.

---

# Cards

Cards are the primary storytelling component.

A card should feel like holding a page from a premium travel journal.

Cards should prioritise:

Photography

Restaurant identity

Personal memories

Context

Statistics should remain secondary.

---

# Icons

Icons support recognition.

They should never replace clear information.

Use icons sparingly.

Avoid decorative iconography.

---

# Empty States

An empty state is an opportunity.

It should encourage exploration.

Examples:

Instead of:

"No restaurants visited."

Use:

"Your culinary journey starts here."

The tone should remain warm, optimistic and understated.

---

# Loading States

Waiting should feel intentional.

Prefer elegant skeleton loading over spinners whenever practical.

Loading should reassure rather than distract.

---

# Success States

Celebrate meaningful moments.

Adding a new visit should feel rewarding.

Completing a personal milestone should feel memorable.

Celebration should remain subtle.

The memory matters more than the animation.

---

# Error States

Errors should remain calm.

Never blame the user.

Explain the issue clearly.

Offer the next logical action.

---

# Accessibility

Premium design is inclusive design.

Every interaction should remain usable for everyone.

Support:

- Dynamic text sizes
- Screen readers
- Colour contrast
- Reachability
- Touch targets

Accessibility is a design requirement, not an enhancement.

---

# Premium Rules

Michelin Passport deliberately avoids:

- advertisements
- clutter
- visual noise
- unnecessary settings
- excessive colours
- dark patterns
- clickbait
- engagement mechanics

Quality is always preferred over quantity.

---

# What We Are Not

Michelin Passport is not:

- a review platform
- a social media feed
- a booking application
- a restaurant discovery engine
- a food delivery service

It is a personal archive of extraordinary culinary experiences.

---

# Design Inspirations

Our inspiration comes from products and brands that embody timeless quality.

Examples include:

- Apple
- Leica
- Aman
- Porsche
- Day One Journal
- Monocle
- The Michelin Guide

We study these products to understand their principles, not to imitate their appearance.

---

# Decision Framework

Every design decision should answer these questions:

Does it make the memory more important?

Does it reduce complexity?

Does it feel timeless?

Does it respect our design values?

Would removing it make the experience better?

If the answer is yes, remove it.

---

# Design Standard

The interface should always feel:

Elegant.

Intentional.

Enduring.

---

# North Star

> Michelin Passport is not designed to showcase restaurants.

> It is designed to preserve a lifetime of unforgettable experiences.
