# 🍷 Michelin Passport

Michelin Passport is a premium Flutter application that enables food lovers to build their own digital culinary passport.

The app allows users to track Michelin-starred restaurants, Michelin Key hotels and other exceptional dining experiences around the world.

---

## ✨ Vision

Michelin Passport is not just another restaurant tracker.

Our ambition is to become **the platform for culinary experiences**, where users can:

- 📍 Keep track of visited restaurants
- 🍽️ Record multiple visits per restaurant
- ⭐ Rate food, service, atmosphere, wine and value
- 📸 Store photos and memories
- 🌍 Explore visited restaurants on an interactive globe
- 🏨 Discover Michelin Key hotels
- 📊 View personal dining statistics
- 🗺️ Plan future culinary trips
- 👥 Share experiences with friends (future)

The goal is to build an application that people enjoy using for years as their personal culinary diary.

## 🎯 Design Principles

Michelin Passport is built around a few core principles:

- Build once, scale forever.
- Quality over speed.
- Beautiful by default.
- Data is an asset.
- User experience comes first.

Every technical and product decision is made with long-term scalability and a premium user experience in mind.
