# Nemea (GR) — boundary notes

**Official text:** technical file PDO Νεμέα (PDO-GR-A1573), eAmbrosia attachment 10693 (raw/gr_nemea_ts.pdf/.txt), section 5: zone set by Royal Decree 539/4-8-1971 (ΦΕΚ 159/Α/14-8-1971), amended by PD 446/10.6.1974 (ΦΕΚ 174/Α/25.6.1974), PD 457/15.9.1988 (ΦΕΚ 210/Α/26.9.1988) and PD 21/21.1.1995 (ΦΕΚ 16/A/31.1.1995). eAmbrosia record 2018-06-08, no later publication. minagric.gr not reachable (Access Denied).

**Wording:** "περιλαμβάνει τις κοινότητες: Αηδόνια, Αρχαίες Κλεωνές, Αρχαία Νεμέα, Ασπρόκαμπος, Γαλατάς, Δάφνη, Καστράκι, Κεφαλάρι, Κούτσι, Λεόντιο, Μποζικά, Νεμέα, Πετρί, Τιτάνη και Ψάρι που ανήκουν στο Νομό Κορινθίας και τις κοινότητες Γυμνό και Μαλανδρένι που ανήκουν στο Νομό Αργολίδας."

**Units:** 17 communities → 17 LAU (all whole).
- Δήμος Νεμέας (EL_4204, no municipal units): all 10 of its communities: Νεμέας, Αηδονίων, Αρχαίας Νεμέας, Αρχαίων Κλεωνών, Γαλατά, Δάφνης, Καστρακίου, Κουτσίου, Λεοντίου, Πετρίου.
- Δήμος Σικυωνίων (EL_4206): Μποζικά 42060113, Τιτάνης 42060117 (ΔΕ Σικυωνίων); Ασπροκάμπου 42060202, Κεφαλαρίου 42060206, Ψαρίου 42060210 (ΔΕ Στυμφαλίας).
- Δήμος Άργους-Μυκηνών (EL_4102): Γυμνού 41020602 (ΔΕ Λυρκείας), Μαλαντρενίου 41020403 (ΔΕ Κουτσοποδίου).

**Judgement calls (transliteration and homonyms):**
- The text lists pre-2011 communities in the nominative; LAU names are genitive (Αηδόνια → Αηδονίων, Κούτσι → Κουτσίου, etc.). Each matched only within the named prefecture (Κορινθία = code 42, seat Κορίνθου 42010101; Αργολίδα = code 41, seat Ναυπλιέων 41010101).
- Homonyms resolved by prefecture: Δάφνη (12 elsewhere), Καστράκι (4 elsewhere), Κεφαλάρι (also EL_41020106 in Argolida and EL_02020205; the text puts Κεφαλάρι under Κορινθία → 42060206), Ψάρι (also EL_40030317, EL_44040309), Γυμνό (also EL_29030203; the text puts it under Αργολίδα → 41020602), Πετρί (only Πετρίου 42040010 is an exact form).
- **Μαλανδρένι → Δημοτική Κοινότητα Μαλαντρενίου (EL_41020403):** νδ/ντ spelling variant of the same name; it is the only candidate in Argolida (or anywhere), so accepted.

**Held back:** none.

**Style notes:** red_acidity left null: only winesofgreece.org describes it ("medium acidity", "refreshing acidity"); no second site. red_tannin 3 reflects a sourced range: soft in young wines (winesofgreece.org, Wine Folly "smooth tannins"), denser in premium oak-aged wines (The Wine Society, winesofgreece.org). red_body 4 from the technical file ("μαλακό και πλούσιο σώμα") and Wine Folly ("fuller-bodied").
