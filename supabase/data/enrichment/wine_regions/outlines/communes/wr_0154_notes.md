# Badacsony (HU): boundary notes

**Official text:** EU single document after the approved standard amendment PDO-HU-A1506-AM02 (OJ C/2024/7443, 16.12.2024, http://data.europa.eu/eli/C/2024/7443/oj; raw/oj_c2024_7443_en.txt), section 6: "Areas of the following municipalities that are classified as Class I or II according to the vineyard cadastre", 16 municipalities. The national product specification, version 2 (boraszat.kormany.hu, current version listed on https://boraszat.kormany.hu/badacsony), section IV, gives the same 16. The amendment did not change the area. eAmbrosia still flags an amendment in progress; no newer text was found.

**Units:** 16 GISCO LAU 2024 (HU_ + KSH code), each an exact name match; KSH 2024 gazetteer confirms all 16 in Veszprém county with the same codes.

**Judgement call:** the Class I/II restriction is the general formula used for every Hungarian region; partial left empty, as for Somló. Tapolca is a town whose LAU includes much non-vineyard land.

**Rows:** 16; partial 0.
