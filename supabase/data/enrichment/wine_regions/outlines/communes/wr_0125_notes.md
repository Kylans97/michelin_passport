# Naoussa (GR) — boundary notes

**Official text:** technical file PDO Νάουσα (PDO-GR-A1610), eAmbrosia attachment 11098 (raw/gr_naoussa_ts.pdf/.txt), section 5: zone set by Royal Decree 502/16.7.1971 (ΦΕΚ 150/A/26.7.1971), amended by Presidential Decrees 320/7.8.1995 (ΦΕΚ 175/A/22.8.1995) and 91/7.10.2011 (ΦΕΚ 224/Α/26.10.2011). eAmbrosia shows no later amendment publication (record date 2018-06-08). The minagric.gr copy could not be fetched (Access Denied), so a later national amendment cannot be ruled out.

**Wording:** "Οι αμπελώνες της ζώνης του ΠΟΠ Νάουσα εκτείνονται στις περιοχές της Δημοτικής Κοινότητας Κοπανού και των Τοπικών Κοινοτήτων Λευκαδίων και Μαρίνης, της Δημοτικής Ενότητας Ανθεμίων, της Δημοτικής Κοινότητας Νάουσας και των Τοπικών Κοινοτήτων Γιαννακοχωρίου, Στενημάχου και Ροδοχωρίου της Δημοτικής Ενότητας Νάουσας του Δήμου Νάουσας καθώς και των Τοπικών Κοινοτήτων Τριλόφου και Φυτειάς της Δημοτικής Ενότητας Δοβρά του Δήμου Βέροιας του Νομού Ημαθίας".

**Units:** 9 communities → 9 LAU.
- Δήμος Νάουσας (EL_0803), ΔΕ Νάουσας (…01): Νάουσας 08030101, Γιαννακοχωρίου 08030103, Ροδοχωρίου 08030104, Στενημάχου 08030105.
- ΔΕ Ανθεμίων (…02): Κοπανού 08030201, Λευκαδίων 08030203, Μαρίνης 08030204.
- Δήμος Βέροιας (EL_0801), ΔΕ Δοβρά (…04): Τριλόφου 08010404, Φυτειάς 08010405.

**Judgement calls:** the text is already in Kallikratis units (it names municipality, municipal unit and community), so matching is by code position, then name. Μαρίνη also exists in Florina (EL_17010210) and Τρίλοφο in five places; only the Imathia ones sit in the named municipal units. ΔΕ Δοβρά = code unit 080104 (seat community Αγίου Γεωργίου; the two named communities are in it). Spelling: text "Φυτειάς" vs LAU "Φυτείας" (accent position only). Δημοτική Κοινότητα Επισκοπής Νάουσας, Μονοσπίτων, Χαριέσσης (also ΔΕ Ανθεμίων) and the rest of Βέροια are not in the text and are excluded.

**Held back:** none.
