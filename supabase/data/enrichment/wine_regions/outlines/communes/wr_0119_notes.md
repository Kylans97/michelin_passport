# Villány (HU) — boundary notes

**Official text:** A Villány oltalom alatt álló eredetmegjelölés termékleírása, 7. változat (applies to grapes harvested after 1 August 2026), section IV. https://boraszat.kormany.hu/download/f/12/a3000/VILL%C3%81NY_term%C3%A9kle%C3%ADr%C3%A1s_2026_7_v%C3%A1ltozat_kn.pdf (raw/hu_villany_v7.pdf/.txt). Listed as the newest version on https://boraszat.kormany.hu/villany (checked 2026-11-21). eAmbrosia EUGI00000006801 / PDO-HU-A1381 shows "amendments in progress" (modification 2026-09-02); the EU register has not published a newer area text.

**Wording:** "Bisse, Csarnóta, Diósviszló, Harkány, Hegyszentmárton, Kisharsány, Kistótfalu, Márfa, Nagyharsány, Nagytótfalu, Palkonya, Siklós, Szava, Túrony, Villány, Villánykövesd, Vokány településeknek szőlő termőhelyi kataszter szerint I. és II. osztályú határrészeibe tartozó területek."

**Units:** 17 settlements → 17 LAU, all Baranya county.

**Method:** as for Tokaj (KSH 2024 code → HU_ + code; names unique nationally; LAU names equal).

**Judgement calls:** class I/II cadastre restriction recorded as the general formula, `partial` empty. Earlier versions (v5, v6) were not compared unit by unit; v7 is the version in force for the current harvest.

**Held back:** none.

**Style notes:** Kékoportó in the spec is Portugieser (the spec itself uses "Portugieser fajtafeltüntetéssel" for the same grape; bor.hu and tastehungary confirm the former name). red_acidity 2 rests on Wine Folly ("subtle acids") and tastehungary ("the wines generally lack acidity"); the spec's Super Premium description says "élénk, érett savszerkezet", which applies to the top tier only. Grape order: Cabernet Franc as flagship (spec, wineanorak), Cabernet Sauvignon most planted and Portugieser second (bor.hu), then Merlot and Kékfrankos (Wine Folly list order, not a ranking).
