# Eger (HU) — boundary notes

**Official text:** Az Eger oltalom alatt álló eredetmegjelölés termékleírása, 6. változat (grapes harvested after 1 August 2023), section IV, version linked from https://gi.kormany.hu/foldrajzi-arujelzok: https://boraszat.kormany.hu/download/e/82/23000/Eger_OEM_term%C3%A9kle%C3%ADr%C3%A1s_v6_KN.pdf (raw/hu_eger_v6.pdf/.txt). A second "v6" file on https://boraszat.kormany.hu/eger (raw/hu_eger_v6b.txt) still contains the Bikavér and Csillag types; the gi.kormany.hu file has them removed, matching the separate Egri Bikavér and Egri Csillag specifications ("eredeti változat", from the 2023/2024 wine year; raw/hu_egri_bikaver.txt, raw/hu_egri_csillag.txt). The area list is identical in both v6 files. eAmbrosia: Eger EUGI00000005122; Egri Bikavér (PDO-HU-02982) and Egri Csillag (PDO-HU-02981) have status "applied".

**Wording (Classicus):** "Aldebrő, Andornaktálya, Demjén, Eger, Egerbakta, Egerszalók, Egerszólát, Feldebrő, Felsőtárkány, Kerecsend, Maklár, Nagytálya, Noszvaj, Novaj, Ostoros, Szomolya, Tarnaszentmária, Tófalu és Verpelét települések a szőlő termőhelyi kataszter szerint I. és II. osztályú határrészeibe tartozó területek" (Superior/Grand Superior: same settlements, class I and II/1).

**Units:** 19 settlements → 19 LAU. 18 in Heves county; **Szomolya is in Borsod-Abaúj-Zemplén** (KSH 2024, code 18892) — recorded as found, not a mismatch (the name is unique nationally).

**Method:** KSH 2024 code → HU_ + code; LAU name equal in every case.

**Judgement calls:** the Eger PDO area is used for the region. The Egri Bikavér area is narrower (no Aldebrő, Feldebrő, Tófalu; Verpelét and Tarnaszentmária only for named vineyards) and is not drawn separately.

**Held back:** none.

**Style notes:** red_tannin left null: the Bikavér spec says "tanninhangsúly nélkül" / "nem lehet tanninhangsúlyos" while Wine Folly calls Bikavér "rich in tannin" — sources conflict. red_body 4 from Wine Folly ("fuller-bodied") and the spec (Superior "érett, testes", Grand Superior "Testes, gazdag telt"); Classicus is lighter. red_acidity 4 from the spec (Eger wines richer in natural acids than more southern regions; cool nights), bor.hu (mountain winds bring "fresh Eger acidity") and wineanorak ("climate is cool"). Kadarka: bor.hu (spread in Eger under Ottoman occupation), Wine Folly Hungary guide (grown mainly in Szekszárd and Eger, a Bikavér component).
